# Enterprise AI Hub — Public Demo

A 30-screen Business User design walkthrough with entirely fictional content. Actions and results are simulated. Do not enter personal, confidential or real business information.

[Open the public demo](https://ashishlookhear-creator.github.io/enterprise-ai-hub-public/) · [Read the public PRD](PRD.md) · [Sanitization notes](SANITIZATION.md)

## Run locally

Download this repository, then open index.html in your browser. No installation, accounts, API keys or backend services are required. Choose a screen from the selector at the top.

## Scope

Includes app discovery, Copilot, citations, knowledge, automations, requests, authorization status, reports, notifications, usage and preferences. Download text report produces a fixed synthetic sample on your device.

The public release contains static HTML and documentation. Authentication, AI generation, RAG, workflow execution, storage and integrations remain future implementation work.

## Privacy and safety

File selection is disabled. Application code has no external requests, analytics, browser persistence or model calls. A browser content policy blocks connections and form submissions. GitHub hosting may process standard request metadata under its own privacy policy. The GitHub owner and web commit identity are public platform metadata.

This repository has a fresh history independent of the private working project. Private project files and design exports are excluded.
